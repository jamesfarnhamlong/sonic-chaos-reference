# Attribution

Sonic Chaos game code and data are original game material. The partial disassembly supplied for this work credits RF / Ravenfreak / Amber Davis and notes contributions by Hivebrain.

This package adds research annotations, reproducible extraction tools, a bounded reference translation, test fixtures and reports. `archive/continuation-01/` preserves the entire earlier package; `asm/previous/` and `docs/continuation-01.md` retain copies for reference. `asm/recovered/` is regenerated by the current decoder script.

Third-party tools are installed separately and retain their own licenses. No blanket license is assigned here to the original game code, decoded game data, or upstream disassembly. A license for new project material can be selected when establishing the public repository.
