## Controlled 5× processing trial
- **Absolute control:** original **nearest-neighbour 5×** for native/wide background and source title.
- **Direct alternative:** **xBRZ 5×** supports factors 2–6; its edge reconstruction can round outlines and infer colours, so it is a *candidate*, not a mandatory style or source truth. Compare with full palette/fade correctness and pixel aliasing.
- **HQx** typically operates at 2×/3×/4×, **Scale2x/EPX** at 2× (Scale3x and 4× variants exist): can compare on *cropped source elements/asset variants*, but do **not** automatically apply another fractional 2.5× to a 2× result and call it a clean 5×; fractional resampling can make uneven pixels. If using these methods, explicitly justify how final 5× output respects pixel grid, alpha and palette edges. Can instead use conservative 5× nearest for integrated screens and apply enhancement only to carefully chosen source elements, or compare xBRZ direct 5×.
- **No blanket world art processing.** Keep all original Sonic/Tails gameplay, terrain, ROM palettes and CRT option untouched. Intended scope is six Enhanced **presentation** screens only. Preservation of per-frame animation/timing/audio, consistent filter across sequential reveal frames, font outlines and transparency edges must be tested. Do not claim sharpening restores genuine extra details; only reshapes edge pixels.
