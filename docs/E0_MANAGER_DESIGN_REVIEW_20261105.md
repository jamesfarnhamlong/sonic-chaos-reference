## Manager design recommendations requiring Chief approval
1. Prefer **existing inherited static final SEGA logo frame**, centered on black, silent, up to ~1 second, skip-safe, with explicit PC-only artwork provenance in documentation. Avoid forcing `PC presentation` text onto the splash unless Chief wants it. The option using the very small ROM title-copyright SEGA lettering is authentic art but not the familiar large striped logo Chief originally envisioned.
2. Preserve binary modes only; make **Enhanced Options visibly indented directly below Enhanced and keyboard/gamepad discoverable with Up/Down**, not accessible *only* by pressing Right. Options is an action, not a third mode. It opens the empty page then Back returns to Enhanced focus; choosing either mode proceeds to the exact same original cinematic. Existing report's Right shortcut is permissible but should not be the sole discoverability route.
3. Classic highlighted on every fresh launch; no mode change during gameplay in E0. Mode committed once at shell exit, maintained in namespaced session state through ordinary title/continue/game over; app relaunch required to change mode. This is a deliberate E0 simplicity choice subject to Chief acceptance.
4. Empty registry, empty Enhanced options page (`No additional features installed`), no fictional feature switches or persistent settings writes. Future enhancements get central stable IDs and effective-value resolver. Classic always resolves all features off. Existing `settings.ini`, campaign RAM and project save namespace must remain unchanged. Future `enhancements.ini` should only be created when actual features exist.
