## Verified actual private GitHub R22 source causes
Examined private source at `SonicChaos_POC` SHA `97b88d0754d41fb9b8fce637da309603d28d1693`:
1. `verification/r22/reproduction/target.gml` uses `file_text_open_write("R22FEATURETRIALTEST-"+name+".json")`, `surface_save(application_surface,"R22FEATURETRIALTEST-native-...png")` and `screen_save_part("R22FEATURETRIALTEST-output-...png",...)`. Its `run_target.py` hardcodes `S=Path('C:/Users/james/AppData/Local/SonicChaos')` and COPIES matching new files from that directory to evidence `captures-target-...` but **does not remove the AppData originals**, so a test run can leave many JSON/PNG artifacts in the normal user-data root. Some R22 other test runners likewise use appdata path and trial filename prefixes. This is an agent/test-process hygiene defect, not a user mistake, not evidence of thousands of user saves or malware.
2. The packaged R22 trial was compiled via `verification/r22/reproduction/build_trial.py` which replaces in build-only source `enhanced_campaign_v1_` → `R22TRIAL_campaign_`, `enhanced_display_v1.ini` → `R22TRIAL_display.ini`, `settings.ini` → `R22TRIAL_settings.ini`, `saveGame` → `R22TRIAL_saveGame`; wraps some diagnostic writers with `R22TRIAL_`. Original source code is restored after packaging (verified by agent). Result: original normal saves can still be present on disk, but the R22 TRIAL READS ITS OWN DIFFERENT NAMES and will not automatically pick up an older R20TRIAL, R19TRIAL or normal save. This is deliberate isolation for safely protecting saves during development but **bad version-to-version UX** for Chief's evolving natural test progress. It is not evidence that those earlier save files were overwritten.
3. `scripts/SCR_chaos_s2/SCR_chaos_s2.gml` contains the canonical name `chaos_campaign_path(slot,gen)` = `"enhanced_campaign_v1_slot"+string(slot+1)+"_"+string(gen)+".json"`, and `chaos_campaign_store` reads **TWO alternating generations (0 and1) per numbered slot1..5**, validates each and picks the newest valid `seq`. R22 trial names map directly to `R22TRIAL_campaign_slot1_0.json` / `R22TRIAL_campaign_slot1_1.json`, and the R20 trial to `R20TRIAL_campaign_slot1_0.json` /`R20TRIAL_campaign_slot1_1.json`. **Both generation files should travel together when deliberately migrating a trial save.** Internal version/seq/integrity fields must remain intact; copying changed file contents or hand editing progress is not authorised.
4. Test-runner `protected()` hashes normal `saveGame*` and `enhanced_campaign_v1_*` before/after and reports unchanged in test sessions, but this is NOT a complete present-time inventory of Chief's local earlier `R20TRIAL_` (or other trial) save contents.
